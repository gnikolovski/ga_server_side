INTRODUCTION
------------

Google Analytics - Server Side is a Drupal module designed to send events
directly to Google Analytics using HTTP requests.


REQUIREMENTS
------------

The Google Analytics - Server Side module requires the installation of both the
Drupal Commerce and State Machine modules.


INSTALLATION
------------

* Install as you would normally install a contributed Drupal module.
  See: https://www.drupal.org/docs/extending-drupal/installing-modules
  for further information.


CONFIGURATION
-------------

You can configure the module at the following page:

```
/admin/config/services/ga-server-side
```

The configuration and usage details of the Google Analytics - Server Side module
are provided on [https://gorannikolovski.com/blog/drupal-google-analytics-4-and-commerce-events](https://gorannikolovski.com/blog/drupal-google-analytics-4-and-commerce-events#configuration-and-usage).
